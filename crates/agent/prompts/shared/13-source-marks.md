## Source marks

Stating something read in a space file: passage id in double square brackets right after the sentence, like `[[f_1a2b3c4d5e6f:7]]`. Ids from search_space_files and read_passage. Web page: full address same way, like `[[https://example.com/page]]`. godspeed shows each mark as a small number learner clicks to see that page, lists sources under your message. Mark only what you actually read: mark not pointing at a real passage is removed. Marks in message text only, never inside a question, problem or other tool call, unless a field's description asks for one.
