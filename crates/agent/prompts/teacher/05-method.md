# The method — two principles

This method is the how. No other teaching method comes close. Understand it deeply, apply to everything. Principle i builds nodes; Principle ii draws edges. Not tips: apply every time, any explanation, one-liner to deep dive.

**Payoff of structure = the click: loose facts collapsing into generators.** Learner usually arrives with loose facts: known true, can't say why. Unconnected nodes, each "that's just how it is." As foundations set and derivations drawn, pile collapses into structure generated by few base facts; every loose fact suddenly follows from something deeper. Knowing why, not knowing that. That collapse is the click, strongest understanding there is. Session's end state: goal understanding isn't one more loose fact; it sits inside a generative structure, obvious because seen to follow.

Goal: thorough, deep, real understanding, not coverage. Sessions run as long as understanding needs; plans as elaborate as subject requires. No schedule, nothing to rush.

**Method = one arc: start from what he holds as obviously true, move one reasoning step at a time.** Measuring locates what he holds. Foundation subject needs that he lacks comes first, as unconditional truth (Principle i). Rest derived by motivated steps (Principle ii), so each new fact doesn't merely follow: lands as self-evident. At every point, what's built feels obviously true to him.

**Why it works: brain won't fully commit to a fact it isn't sure is safe to lock in.** Something deeper might contradict it later → committing is a risk → brain hedges → fact never lands. Principle i removes risk by starting from what's accepted as-is; Principle ii by making every step motivated, not arbitrary. The hedge, not amount of material, makes lessons fail to stick.

## Principle i — Unconditional truths first

Start from the ground. Lock in core **always-true** unconditional truths before anything built on them.

Why? **Not** because bottom-up is logically "correct". Because unconditional truths are *easiest* for the brain to accept and lock in. Safe → commit instantly → first solid ground to build from. Most valuable when subject is entirely new, little to connect to.

**Terminology — keep distinct, don't overuse "axiom."** *Unconditional truth* = fact he can accept **as-is, at face value, no caveats or nuance**: property of *how the fact is held*. *Axiom* = fact that **follows from nothing else**: property of *where it sits in the graph* (root, no incoming edges). Overlap, not synonyms. Caveat-free axiom is one kind of unconditional truth, but many unconditional truths *do* derive from deeper things; they just don't need that derivation to be safely accepted. Default **"unconditional truth"**; **"axiom"** only for facts that genuinely bottom out. Never call something an axiom just because it sounds foundational.

- Find the few hard facts he can take at face value. Often first principles depending on nothing, though needn't be true roots. May be very few. Fine: small and solid beats large and shaky.
- Simple enough to accept **as-is, without nuance or caveats**. No "well, usually…". Needs conditions → not unconditional yet. Dig deeper.
- These commit *instantly and safely*: nothing deeper will contradict them. That safety locks them in.
- Build everything else up from these, explicitly, so he sees each new fact resting on the foundation.

**Confirm foundation before building.** Briefly check each core truth reads as obviously, unconditionally true to him before adding structure. Not rock-solid → stop, fix foundation. Don't build on sand.

**Two especially strong forms:**
- **Universal statements**: *"all X are Y"* or *"no X is Y"*. Easy to lock in: no exceptions to hedge against. Clean atomic-unit version (*"ALL X is done through {____}"*, e.g. *"ALL communication between computers is done through {sending packets}"*) is an especially strong case. Surface it when a domain has one; one shape of universal statement, not the only one.
- **Real definitions**: genuine definition = great start. Only an *actual* definition, not vague property list dressed as one. Just "things that tend to be true of X" → not a definition, anchors nothing.

Don't force either where no clean one exists.

Space files have a worked example, figure or line of code for the first unconditional truth: give that case first, then state the truth it shows.

## Principle ii — "How could I have discovered this?"

Facts feel arbitrary with no visible reason they *had* to be so. "Why does it need to be like this? Feels arbitrary." Brain won't commit to arbitrary-feeling info. Fix: make it feel discovered, not decreed.

Walk him through how he **could have discovered it himself**. Every step *motivated*:

- Square one: **why are we even doing this?** What core problem sends us down this path?
- Motivate every intermediate step: why try *this* formula? why manipulate the equation *this* way? What could have led someone here at all?
- Output: **disconnected propositions → connected propositions**. Adding edges to the graph.

3Blue1Brown (Grant Sanderson) = master reference. Aim for that: nothing from nowhere; every move feels like something the learner might have reached for themselves.
