# 8.1 The outside-agent boundary: how Claude Code starts

The arguments and settings every Claude Code start passes, and what each one leaves out or sets.

## Claude Code's start

Every Claude Code start (the teacher's three, the helper's and the copied command) passes the same arguments (`CLAUDE_ARGS`, `core::spaces::agent_folder`). The teacher needs godspeed's tools and nothing else; everything else loaded at start is standing context that every request pays for (the learner's own plugins, MCP servers, skills and the Artifact tool can add tens of thousands of tokens).

| Argument or setting | What it leaves out or sets |
|---|---|
| `--settings .godspeed/claude-settings.json` | The folder's settings, hooks and permissions, loaded before the folder is trusted |
| `--strict-mcp-config --mcp-config .mcp.json` | Only godspeed's server; the learner's own MCP servers (user, project, plugins) stay off |
| `--disallowedTools Agent Skill` | The subagent tool, and the learner's skills (their list is standing context). Slash commands stay, so `/compact`, `/clear`, `/model` and `/resume` work in the terminal |
| `--autocompact 150000` | The chat compacts at 150,000 tokens ([compaction](../compaction-accounting.md#the-teacher-session)) |
| `enableArtifact: false` | The Artifact tool |
| `disableClaudeAiConnectors: true` | claude.ai connectors |
| `syncClaudeAiSkills: false`, `syncClaudeAiPlugins: false` | Skills and plugins synced from the learner's claude.ai account |
| `env.GODSPEED_WAKES` | Tells the connector the waiter wakes this session |

The flags that take several values (`--mcp-config`, `--disallowedTools`) come before `--autocompact`, so a prompt after them stays the prompt. Before it starts Claude Code, the script runs `claude --version` through `.godspeed/new-enough.mjs`: older than 2.1.330 (the version tested with the waiter's `asyncRewake`; `--autocompact` needs 2.1.221) ends it with exit 6 and "godspeed needs Claude Code 2.1.330 or newer. Update it (run: claude update), then click Start again in godspeed." Output with no version in it passes. A learner's own start command is not asked, since a launcher may not pass the flag on. The helper's script also sets `GODSPEED_HELPER=1`.

In a browser there is no `window.lh.terminals`: Start makes the folder and the learner copies the command into their own terminal.

A learner starting an agent through a launcher sets its command with Change command under the Start button: one line, at most 300 characters (`usable_start_command`). Empty goes back to `claude` or `codex`.

`services::app::old_setup` finds and removes leftovers of the retired Claude Code plugin and old Codex config block. A notice in the strip's peek and a line in Settings, Connection offer Remove.
