# 6.6 Deadline reminders and the menu bar countdown

How godspeed tells the learner about the next deadline outside the window: a daily system notification and the Mac menu bar countdown.

## Deadline reminders

`services::app::deadline_reminder` sends at most one system notification a day, for the soonest open deadline 3 days away or less.

1. Server checks 10 s after start, then every 10 minutes. Each wait reads wall clock, so a computer that slept through 9:00 still sends within 10 minutes of waking.
2. From 9:00 local time on, it picks deadline and writes text, for example "Quiz 2 is in 2 days" with "Algebra. You are 40% ready." (percentage from `progress_for`). A deadline with problems says "Algebra. 2 of 7 problems done." With neither, only space name shows.
3. Server asks shell with `notify`. The shell skips it while main window has focus and answers whether it showed it.
4. Only a shown reminder marks day in `data/reminders.json` (`store::reminders`, `{version: 1, lastDay}`). A skipped one is retried at a later check.

A server without a shell runs no check. Settings, General, Deadline reminders (`general.deadlineReminders`, on by default, desktop app only) turns them off, read at each check.

## Menu bar countdown

On the Mac, the menu bar shows the g logo and the time left to the nearest deadline that is not done and not yet due. Clicking it opens a menu of the next deadlines, then Open godspeed and Quit godspeed. `services::app::menu_bar_countdown` decides the words (`core::spaces::menu_bar_countdown`), and the shell draws them ([The main window](../tauri-shell/magnifier-menu-bar-and-icon.md#menu-bar-countdown)).

| Part | Rule |
|---|---|
| Title | 24 hours or more left: calendar days, "3d" (`days_between`, the count the deadline's page uses). From 1 hour: whole hours, "5h". Under 1 hour: whole minutes, at least 1, "45m". With no such deadline the logo shows alone. |
| Rows | The next 5 such deadlines, soonest first, each the reminder's sentence ("Quiz 2 is in 2 days", `due_sentence`). A name over 40 characters is cut with "…". Two rows with the same name each add their space: "Homework 3 (Algebra) is tomorrow". A row opens `/space/deadline/<id>?space=<space id>`. |

1. The server starts the loop only on the Mac and only with the shell. It sends the words at the start.
2. It keeps its own list of open deadlines and reads the space records again only on `spaces-changed`, once for a burst.
3. It looks again on that event, on a settings save (`MiscState::settings_saved`, poked by every PUT and PATCH of a settings section), and at each whole minute. Each minute's wait reads the wall clock, since timers stop while the computer sleeps.
4. It sends only words that differ from the last ones sent.

Settings, General, Menu bar countdown (`general.menuBarCountdown`, on by default; only an explicit `false` turns it off) removes the item: the server sends `menu_bar_countdown_off` once.
