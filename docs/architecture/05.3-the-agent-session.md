## 5.3 The agent session

Each lesson runs on its own session of the learner's agent (Claude Code or Codex, `agent` in `data/agent-folder.json`), in the godspeed folder (`services::turns::lesson_session`). A new session starts on the model the learner picked for that agent (`model: {claude, codex}` in the same file, set by `PATCH /api/agent-folder {model}`), else on the agent's own default. Jobs keep the agent's own default.

| Piece | Where | What it does |
|---|---|---|
| `agentSession` | lesson record | `{agent, id, promptHash, seen}`: the session that holds the lesson, the hash of its instructions and tools, the last message it saw |
| `turn_input` | `core::messages::native_messages` | Sends only the record past `seen`; an answer to the session's own question is led by `side_answer_lead`. Notes on the last reply go first, the learner's rules after the record for a session that goes on, and on the day a homework lesson is due, the time now and the time due last (`due_today_line_for`, [7.2](07.2-lessons-on-files-and-homework.md#homework-sessions)) |
| `ToolHost` | `engine::turn::tool_host` | Runs godspeed's tools; a clean question call ends the turn |
| `TranscriptBuilder` | `engine::turn::record` | Writes the session's events as the record's messages; the agent's own tools are desk steps only. A step's `turn_end`, which brings its results to the window, goes out once each of its calls has its result. Claude Code names a step's calls before they run, so they share one message and each call's check sees them all. A call whose result is held (`held: true`) stays out of the record until a later call releases it (`releases`) |

A new session opens with the summary and the kept tail when the agent or the hash changed, a compaction cut came after `seen`, the agent cannot resume the session, the agent compacted its own history, or the learner pressed Try again. An open session closes after 10 idle minutes.

A Study plot and its guess pass as a pair within one turn, in either order (`agent::tools::lesson_parts`). Whichever comes first is held: the agent reads what is missing, and the turn goes on. When the other comes, both are stored as one reply stores them, and the turn ends on the guess. A half still held at the turn's end is never shown and becomes a note before the next reply.

Checks: `check_cites` runs on each finished text, and the record keeps the checked text. A Study call whose words read as a curve is refused. A Study reply's own words were already shown, so its nudges and removed source marks become notes the agent reads before its next reply (`services::turns::reply_nudges`).

Stop interrupts the agent and the running tools. A permission question from the agent waits on the lesson's desk (`approvals` on `GET /api/chats/{id}/work`) until `POST /api/chats/{id}/approvals/{approvalId} {allow}`; Stop or the turn's end denies it. A message sent during the turn goes to Codex at once and to Claude Code as its next turn.
