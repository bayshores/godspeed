## 6.3 Paths

A learner with no syllabus and no files (a job, a skill) gets a path: the topics toward a goal, in order. The learner's own agent writes it from whatever source the learner names; godspeed ships no roadmap content. The source goes in the space description.

### The record

`path` on the space record (`core::spaces::space_path`, record version 12; an older record reads as having no path):

| Field | Holds |
|---|---|
| `goal` | what the learner works toward, 1 to 40 characters, read after "Path to" |
| `topics` | 1 to 40 topics in order, each `{id, name, covers}`: a 1 to 4 word name and one line on what it covers |

- The agent sends `path` with `create_space` or `update_space`. Sending it replaces the list. Each answer gives the count and the names it left off, never the list.
- A topic keeps its id while its name stays (case does not matter). A name sent twice is refused.
- Lessons and facts of a removed topic stay.
- The path changes only outside lessons: a Study session gets no space-change tools.

### Where the learner stands

A path topic's id is the plan node of its Study sessions, so an answer counts for it at once, before any fact is read. `core::study::path_progress` tallies the answers with that node id into a status, and picks the next topic by the deadline rule (`study_tier`): the first that is not strong and was not studied today. The progress payload carries it as `path` (`services::graph::progress::path_for`).

- `read_space` shows each topic's name and status, and what the next one covers.
- A Study start on a path topic (`pathTopicId` on `POST /api/chats`, or `start_lesson` with a path topic's name) has that one topic as its plan, the facts born in its earlier sessions as picks, and a note with its place and what it covers.

### In the window

| Where | Shows |
|---|---|
| Progress | the Path block first: "Path to {goal}, 4 of 28", the next topic with what it covers and Study, the next three, "Show all". With no deadline it takes the place of "No deadlines yet" |
| Study page | the next topic as Next up, in place of the next file |
| Today | "Next up: {topic}" where a space with no study files says "No study files yet." |
